# Yusrah Mohammed Portfolio

Personal site for my work as a software developer: web applications, digital products, and blockchain-powered experiences.

Built with React, TypeScript, Vite, and Tailwind CSS.

**Live:** [https://portfolio-hsj4.onrender.com](https://portfolio-hsj4.onrender.com)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
